# Handwritten-Digit-Recognizer

🚀 Handwritten Digit Recognition System using Deep Learning

This project is a CNN-based Handwritten Digit Recognizer built using Python, TensorFlow/Keras, and Tkinter GUI. The model is trained on the MNIST dataset with advanced techniques like Data Augmentation, Batch Normalization, Dropout, Early Stopping, and Model Checkpointing to achieve high accuracy.

✨ Features:

* Train a Convolutional Neural Network (CNN) on the MNIST dataset
* Real-time handwritten digit prediction through an interactive GUI
* Image preprocessing for improved recognition accuracy
* Confidence score display for predictions
* Clean and beginner-friendly code with proper comments

🛠 Technologies Used:

* Python
* TensorFlow / Keras
* Tkinter
* NumPy
* PIL (Pillow)

📂 Files Included:

* Training script for CNN model 
* GUI application for digit recognition 
* Trained model file (.h5)

This project helped me understand Deep Learning, CNN architecture, image preprocessing, and GUI integration in Machine Learning applications.
